# CAM | ABC da Construção

Landing page promocional desenvolvida para a campanha Clube CAM em parceria com a ABC da Construção.  
O projeto apresenta uma narrativa visual forte, seções emocionais, benefícios da campanha, informações institucionais e formulário de cadastro para torcedores e clientes.

## Visão geral

O **Clube CAM | ABC da Construção** é uma landing page criada para destacar a parceria entre o clube e a marca, combinando emoção, identidade visual e conversão.  
A proposta é conduzir o usuário por uma jornada intuitiva: impacto inicial, reforço de campanha, prova de valor, credibilidade institucional e cadastro.

---

## Objetivo

O principal objetivo do projeto é criar uma experiência visual e comercial que:

- destaque a parceria entre o Clube Atlético Mineiro e a ABC da Construção;
- apresente benefícios e diferenciais da campanha;
- valorize a conexão com torcedores e clientes;
- direcione o usuário para o formulário de cadastro.

---

## Estrutura da página

A página foi organizada com a seguinte hierarquia:

  - Seção 5: O estádio e a experiência
  - Seção 6: O lance e a paixão

  - Seção 8: Viver junto com amigos
  - Seção 9: Patrocínio e credibilidade
  - Campanha
  - Benefícios
  - Sobre
  - Dúvidas
- Formulário
- Footer

## Como executar o projeto

Para rodar o projeto localmente:

1. Clone ou baixe os arquivos do repositório.
2. Abra a pasta do projeto no seu editor de código.
3. Verifique se os arquivos estão organizados assim:

```bash
.
├── index.html
├── style.css
├── script.js
└── assets/
```

4. Abra o arquivo `index.html` no navegador.

Se preferir, você também pode usar uma extensão como **Live Server** no VS Code para visualizar as alterações em tempo real.

## Responsividade

A interface foi pensada para funcionar bem em diferentes tamanhos de tela, com:

- adaptação do layout em desktop, tablet e mobile;
- empilhamento das colunas em telas menores;
- imagens com `object-fit: cover`;
- blocos de conteúdo com espaçamento consistente;
- botão e navegação adaptados para interação mobile.

---

## Acessibilidade

O projeto também considera pontos importantes de acessibilidade, como:

- uso de `alt` descritivo nas imagens;
- estrutura semântica com `header`, `main`, `section` e `footer`;
- botões com comportamento claro;
- navegação por âncoras internas;
- contraste visual adequado entre fundo e texto.
