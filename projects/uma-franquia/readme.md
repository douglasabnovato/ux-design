# Uma Franquia ABC da Construção 

Landing page premium para apresentação de acabamentos, revestimentos e atendimento especializado via WhatsApp.

## Visão geral

O projeto **ABC da Construção** foi criado como uma landing page de alta conversão para apresentar soluções em acabamentos, inspirar o usuário com ambientes reais e facilitar o contato com atendimento especializado.

A proposta é unir:
- identidade visual premium;
- prova social e institucional;
- navegação simples e responsiva;
- conversão direta via WhatsApp.

## Funcionalidades

- Hero com headline de impacto.
- CTA principal para atendimento via WhatsApp.
- Seção de prova com indicadores institucionais.
- Área de inspiração por ambiente.
- Galeria visual de ambientes.
- Seção institucional sobre a marca.
- Bloco de localização e contato.
- Botão fixo para voltar à home do UX Design.
- Botão flutuante para voltar ao topo.

## Estrutura da experiência

A página foi pensada com foco em escaneabilidade e conversão:

1. **Hero**
   - Apresenta a marca e a proposta principal.
   - Direciona o usuário para o CTA de WhatsApp.

2. **Prova social**
   - Mostra números e autoridade da marca.

3. **Escolha do ambiente**
   - Cards com cozinha, banheiro, sala e quarto.
   - Cada card oferece um CTA específico para atendimento.

4. **Galeria**
   - Mostra variações visuais dos ambientes.

5. **Sobre a ABC**
   - Explica o posicionamento da empresa como consultora de ambientes.

6. **Localização**
   - Exibe endereço, links para mapa e contato direto.

## Como executar o projeto

### 1. Clonar ou baixar o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

### 2. Abrir a pasta do projeto

Entre na pasta do projeto:

```bash
cd uma-franquia
```

### 3. Abrir no navegador

Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão de servidor local, como:
- Live Server
- http-server
- qualquer servidor estático de sua preferência
