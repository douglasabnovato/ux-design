# 🥗 Restaurant • Módulo UX / Institucional

> **Status:** 🚀 Concluído | **Tipo:** Website Institucional / Cardápio Digital

## 📖 Sobre o Projeto
O **Restaurant** é um website moderno e elegante projetado para expor os produtos, pratos e serviços de um restaurante no ambiente digital. O projeto foca em proporcionar uma experiência gastronômica agradável visualmente, contando com alternância de tema (Dark/Light mode), rolagem suave e animações interativas.

## 🎓 O que o aluno aprende aqui?
- **Metodologia Mobile-First:** Construção do layout pensando prioritariamente em dispositivos móveis e adaptando progressivamente para telas desktop.
- **Tema Claro e Escuro (Dark/Light Theme):** Implementação de chaveamento dinâmico de cores com CSS e JavaScript para melhorar a acessibilidade e preferências do usuário.
- **Animações e Smooth Scroll:** Uso de efeitos de rolagem suave e acionamento de animações conforme o usuário navega pelas seções.
- **Componentização Visual:** Criação de vitrines de pratos, seções sobre o estabelecimento, serviços e depoimentos com usabilidade fluida.

## 🛠️ Tecnologias e Recursos

## 🚀 Funcionalidades Principais
- [x] **Navegação Mobile-First:** Design fluido perfeitamente adaptado para todos os tamanhos de telas.
- [x] **Dark & Light Mode:** Suporte completo para alternar entre tema claro e escuro.
- [x] **Smooth Scroll:** Rolagem suave ao clicar nos links de navegação do menu.
- [x] **Scroll Animations:** Animações dinâmicas ativadas ao rolar a página.
- [x] **Vitrine de Produtos:** Seção dedicada para exibição do menu de pratos e destaques da casa.
