# ☕ Coffee • Módulo UX / Institucional

> **Status:** 🚀 Concluído | **Tipo:** Site Institucional / Cafeteria & Branding

## 📖 Sobre o Projeto
O **Coffee** é um website institucional desenvolvido para cafeterias e marcas do universo do café especial. O projeto combina um design elegante com foco em experiência do usuário (UX) e storytelling, apresentando o ambiente, cardápio e a cultura do café de forma atraente tanto no desktop quanto em dispositivos móveis.

## 🎓 O que o aluno aprende aqui?
- **UI/UX para Marcas de Nicho:** Criação de uma identidade visual marcante utilizando paletas de cores quentes e tipografia que transmitem conforto e sofisticação.
- **Desenvolvimento Responsivo:** Construção de layout adaptável para garagens digitais, smartphones e monitores desktop.
- **Storytelling & Content Strategy:** Como estruturar seções que contam a história do grão, métodos de preparo e o conceito do estabelecimento para engajar o cliente.
- **Benchmarking e Fontes de Inspiração:** Mapeamento de referências de mercado, incluindo clubes de assinatura, blogs especializados e guias de gastronomia.

## 🛠️ Requisitos & Funcionalidades
- [x] **Design Personalizado:** Layout exclusivo construído para o segmento de café.
- [x] **Responsividade:** Adaptação completa da navegação e grids para telas mobile e desktop.
- [x] **Favicon:** Identidade visual aplicada também à aba do navegador.
- [x] **Seção Hero & Galeria:** Exibição de imagens de alta qualidade dos produtos e ambiente.
