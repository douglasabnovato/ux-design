Perguntas frequentes

Como sei que a obra é autêntica?

Cada NFT tem um registro único em blockchain com o endereço do artista que a criou. O certificado aparece na sua carteira após a compra.

O que são royalties?

Uma porcentagem (aqui, 10%) de toda revenda volta automaticamente para o artista original.

O que é RKT?

É o token fictício usado nesta demonstração. Nenhuma transação real é feita.

Preciso de uma carteira?

Sim. Use o botão "Conectar carteira" no topo; nesta demonstração a conexão é simulada.
