# Visita à Obra

Landing page de agendamento técnico para visitas em obras, com foco em captação de leads interessados em avaliação presencial e orientação de projeto.

## Descrição do projeto

Este protótipo apresenta um formulário moderno em estilo Modelo 3, com layout dividido em duas colunas:
- painel esquerdo com proposta de valor, benefícios e prova de confiança
- painel direito com formulário de agendamento de visita técnica

O objetivo é gerar uma experiência clara e objetiva para quem deseja solicitar uma visita de avaliação de obra.

## Estrutura do projeto

- `index.html`: layout principal com conteúdo, texto de conversão e formulário
- `style.css`: estilos visuais, responsividade e identidade gráfica
- `script.js`: lógica de validação do formulário e feedback de envio
- `readme.md`: documentação do projeto

## Fluxo do formulário

- Dados de contato
- Detalhes da obra
- Seleção de ambientes para visita
- Prioridade da visita
- Autorização para receber informações por canais digitais

## Características principais

- layout split-screen com foco em conversão
- campos agrupados em blocos para melhor leitura
- seleção de ambientes em cards interativos
- validação de campos obrigatórios no cliente
- feedback visual de sucesso e erro
- design responsivo para desktop e mobile

## Como usar

1. Abra `projects/form-3/index.html` em um navegador.
2. Preencha todos os campos obrigatórios.
3. Selecione pelo menos um ambiente para visita.
4. Envie a solicitação e veja a confirmação local.

## Personalização

Você pode adaptar este projeto para outros serviços de visita técnica ou orçamentos alterando:
- textos e títulos em `index.html`
- cores, fontes e espaçamento em `style.css`
- regras de validação em `script.js`

## Observação

O formulário atual funciona como protótipo com validação local. Para produção, recomenda-se integrar a submissão com um backend ou serviço de captura de leads.
