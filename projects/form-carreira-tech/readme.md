# Carreira Tech

Projeto de landing page para agendamento estratégico de mentoria e sessões de orientação de carreira em tecnologia.

## Visão geral

Este projeto é um formulário de dois passos feito para capturar leads interessados em mentoria tech e agendar conversas estratégicas.

### Objetivo

- Qualificar rapidamente o perfil profissional do lead
- Coletar informações essenciais antes da conversa
- Agendar um horário ideal para a sessão
- Criar uma experiência de formulário leve e executiva

## Estrutura do projeto

- `index.html`: página principal com o formulário em duas etapas
- `style.css`: estilos visuais, tipografia e responsividade
- `script.js`: lógica de navegação entre etapas, validação de campos e mensagens de feedback

## Fluxo do formulário

### Etapa 1
- Cargo / momento profissional atual
- Faixa salarial / faturamento atual
- Maior obstáculo atual

### Etapa 2
- Nome completo
- E-mail
- WhatsApp
- Melhor turno para a conversa

## Características principais

- design executivo e moderno
- stepper visual (1 de 2 / 2 de 2)
- campos em formato de cards para melhor usabilidade
- validação de formulário no cliente
- feedback de erro e mensagem de sucesso

## Como usar

1. Abra `projects/form-carreira-tech/index.html` no navegador.
2. Preencha a Etapa 1 e avance para a Etapa 2.
3. Confirme os dados e envie a inscrição.

## Personalização

Você pode adaptar o projeto para outros temas de mentoria ou consultoria tech alterando:

- textos do `index.html`
- cores e estilos em `style.css`
- validações em `script.js`

## Observação

Este protótipo utiliza validação local apenas para demonstração. Em produção, integrá-lo com um backend ou serviço de captura de leads é recomendado para armazenar e processar os dados.
