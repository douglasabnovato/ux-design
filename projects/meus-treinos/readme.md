# 🏋️‍♂️ Meus Treinos • Módulo UX / Saúde & Fitness

> **Status:** 🛠️ Em Desenvolvimento | **Tipo:** Aplicação Web / Gestão de Treinos & Saúde

## 📖 Sobre o Projeto
O **Meus Treinos** é uma aplicação voltada para o acompanhamento e registro de atividades físicas, fichas de musculação e progresso corporal. O projeto permite armazenar rotinas de treinos (Divisão ABC: Pernas, Empurrar e Puxar), histórico de frequência, rotina de suplementação, planos alimentares e avaliações físicas, servindo de ponte entre o praticante, personal trainers e instrutores.

## 🎓 O que o aluno aprende aqui?
- **Modelagem de Dados Fitness:** Estruturação de dados complexos para séries, repetições, intervalos de descanso e rotinas divididas (Treinos A/B/C).
- **UX/UI para Aplicações de Acompanhamento:** Design de dashboards responsivos focados no acompanhamento de métricas e evolução do usuário.
- **Integração com JSON & Mídias:** Manipulação de dados estáticos via objetos JSON e fluxo de upload de fotos de fichas físicas e relatórios.
- **Protótipos & Design Systems:** Uso de referências do Figma e templates W3.CSS para prototipagem rápida de layouts de academia e condicionamento.
