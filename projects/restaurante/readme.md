# 🍔 Food • Módulo UX / Institucional Gastronômico

> **Status:** 🚀 Concluído | **Tipo:** Site Institucional / Restaurante & Gastronomia

## 📖 Sobre o Projeto
O **Food** é um website institucional projetado para restaurantes e estabelecimentos do setor alimentício. O projeto combina um design apetitoso e moderno com foco em experiência do usuário (UX), apresentando o cardápio, a proposta gastronômica e os diferenciais da casa de forma clara em qualquer tipo de tela.

## 🎓 O que o aluno aprende aqui?
- **UI/UX para o Setor de Alimentação:** Aplicação de boas práticas de design visual (paleta de cores estimulantes, contraste e fotos destacadas) para engajar o cliente final.
- **Desenvolvimento Responsivo Layout-First:** Adaptação perfeita do menu, seções de produtos e chamadas para ação em dispositivos mobile e desktop.
- **Storytelling e Conceito Gastronômico:** Como integrar entrevistas, receitas e o conceito do "ato de cozinhar" na narrativa institucional do site.
- **Identidade Visual e Assets:** Aplicação de marca personalizada, favicon e tratamento de imagens de pratos.

## 🛠️ Requisitos & Funcionalidades
- [x] **Design Personalizado:** Identidade visual e layout desenhados exclusivamente para o nicho de restaurantes.
- [x] **Responsividade:** Navegação fluida e grids adaptáveis para mobile, tablet e desktop.
- [x] **Favicon Integrado:** Personalização da aba do navegador.
- [x] **Vitrine de Produtos:** Seção visual para exposição de hambúrgueres, pratos e acompanhamentos.
