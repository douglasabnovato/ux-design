# Formulário de Captação para Escola de Programação

Landing page de conversão focada em inscrição de leads para escola de programação.

## Descrição do projeto

Esta página apresenta um formulário otimizado para captar informações qualifi cadoras de potenciais alunos:

- Nome completo
- E-mail
- Experiência em programação
- Motivo para aprender programação
- Área de interesse (Web, Mobile, Dados, UX/Produto)
- Fonte de descoberta da escola

A página combina:

- hero com proposta de valor clara
- blocos de confiança e prova social
- layout em duas colunas com conteúdo à esquerda e formulário à direita
- validação de formulário em JavaScript
- estrutura semântica para SEO

## Estrutura de arquivos

- `index.html`: layout da landing page e formulário
- `style.css`: estilos visuais, responsividade e animações
- `script.js`: validação do formulário e mensagens de feedback
- `readme.md`: documentação do projeto

## Como usar

1. Abra `projects/form-1/index.html` no navegador.
2. Preencha os campos do formulário.
3. Envie o formulário para testar a validação e o feedback.

## Diferenciais do formulário

- apenas uma seção principal para foco de conversão
- campos que ajudam a qualificar o lead antes do contato
- visual moderno com contraste e espaçamento elevado
- mensagem de sucesso e erro acessível

## Personalização

Você pode adaptar este formulário para outros temas digitais alterando:

- textos de `index.html`
- cores e fontes em `style.css`
- regras de validação em `script.js`

## Observações

O formulário atual usa validação no cliente. Para produção, integre um backend ou serviço de formulário para enviar os dados reais.
