# Leis de UX

| Princípio | O que diz | Como aplicar em uma landing page |
|---|---|---|
| Lei de Hick | Mais opções aumentam o tempo de decisão | Uma ação principal por seção |
| Lei de Fitts | Alvos maiores e mais próximos são mais fáceis de acertar | Botão principal grande e fácil de alcançar no celular |
| Efeito Von Restorff | O elemento diferente é o mais lembrado | Só a ação principal recebe a cor de destaque |
| Hierarquia visual | Tamanho, peso e posição guiam a leitura | Um único `h1`, que diz o benefício |
| Psicologia das cores | Cores carregam associações, que variam por cultura | Escolher pela marca e conferir o contraste; não tratar como regra |
